# Unit Economics & Financial Modeling Tool

📇 Комплексная динамическая модель для анализа и прогнозирования юнит-экономики образовательной платформы. Позволяет проводить сценарный анализ и оценивать маржинальность бизнеса на основе когортных данных.

## 🎯 Основные задачи
* **Unit Analysis:** Расчет и мониторинг CAC, LTV и маржинальной прибыли.
* **What-if Modeling:** Оценка влияния изменений Retention, конверсии и CPA на чистую прибыль.
* **Planning:** Расчет маркетинговых бюджетов и необходимой емкости преподавательского состава.

## 🛠 Функциональные модули
* **Главный (Юнит-калькулятор):** Интерактивная панель управления с ключевыми метриками и рычагами влияния на финансовый результат.
* **Acquisition показатели:** Аналитика стоимости привлечения (CAC) в разрезе программ обучения.
* **Retention & Intensity:** Моделирование жизненного цикла студента (LT) и динамики потребления уроков.
* **Операционные расчеты:** Планирование ФОТ и расчет пропускной способности (Capacity Planning) учителей.

## 📈 Методология
* **Когортный анализ:** Учет метрик удержания для точного прогнозирования прибыли.
* **Сценарное моделирование:** Гибкая настройка гипотез для формирования планов (оптимистичный / пессимистичный).
* **Data-driven подход:** Автоматическая консолидация транзакционных данных в аналитические срезы.

## 📂 Структура файла с калькулятором
* `Главный` — визуализация и управление параметрами.
* `План Маркетинга`,`Свод` — воронка регистраций и бюджеты.
* `Найм преподавателей`, `Найм сотрудников`,`CAC's`, `Свод` — модель найма и операционные затраты.
* `Свод`,`CAC's` — расчетные листы (агрегация транзакций, Retention, Интенсивность).
